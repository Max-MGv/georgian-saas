Customer-visible changeG-2 · Per-person items on the public form

Today the guest types a quantity, default 1, even for a per-person item, so "35 ₾ per person" is charged once unless they type the guest count. Flat items also show a quantity box. The plan fixes both (per person × paying guests, flat has no box), so a real Nikalas Marani booking with a per-person masterclass will cost more than it would today. This goes in the release note. Chunk 0 first counts, read-only on production, how many real lines this touches.
