2 · Bank or Cash while a link is still open

Flitt cannot cancel a link — it can only let it expire (7 days). If an admin records Cash while the link is open, the guest could still pay it and be charged twice. So the menu warns before recording, and the status pill shows that a link is waiting (same idea as today’s “Invoice sent” mark).

How was this paid?

A card link for ₾250.00 is still open until 5 Nov 2026, 14:30. If the guest pays it too they will be charged twice — a link can’t be cancelled.

“Card” here reopens the same link (one open link per order) instead of making a second one.
