3 · The Card popup — what the admin sees after choosing “Card”

One shared popup (built from today’s QR dialog + link panel) for every place an admin takes money. The amount is the full amount still owed — it is not editable, exactly like Bank / Cash. The popup checks every few seconds and flips to “Paid” by itself when Flitt confirms, then the page behind refreshes. Closing it does not cancel anything: the link stays valid until the date shown.
