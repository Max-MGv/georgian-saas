7 · “Nothing to pay” — a booking that genuinely costs 0 ₾

All guests free, a partner visit. Marking it Paid is refused (board 6) and “Unpaid” would be a lie that sits in the Unpaid filter forever. So a booking whose total is set and is 0 ₾ gets its own quiet grey state. Not set (no price yet) is different: that one says “Set the price first”. Bookings only — a wine order always has priced wines.
